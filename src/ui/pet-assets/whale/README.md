# Legacy whale archive

This directory preserves the previous desktop-pet artwork for provenance and a
possible future switcher (no switcher or configuration is implemented here).

- `whale.svg` is the exact path and fill previously embedded in `pet.html`.
- `whale_render.png` is the previous 480×480 offline preview.

source comment described it as an “official SVG” under MIT; that statement was
not supported and is intentionally not repeated here. Simple Icons distributes
its own project under CC0-1.0, while its disclaimer says individual brand icons
may have separate rights and that CC0 does not clear trademark rights. DeepSeek
brand/trademark rights may therefore still apply. This file is retained as a
